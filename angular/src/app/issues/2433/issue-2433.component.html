Issue 1: When loading a page with a Tab on it, the initial tab is loaded into the URL automatically, despite never being selected. If the tab is lower down on the page, this causes the page to scroll automatically down to the Tab location, this is undesirable on an initial page load.

Issue 2: hit the back button twice to get to the previous page

If you go to a page with a Tabs component on it, two histories are created in the browser history, one with the tab selected (http://localhost:4200/tabs#All) for example, and then another with just the page (http://localhost:4200/tabs) for example. This means you actually need to hit the back button twice to get to the previous page, despite not having selected a tab or anything. That being said as well, despite having the tabs change the browser URL and history when you select a tab, if you select a new tab, it will create a new browser history with the old tab in the URL, going back does not actually change the selected tab.
