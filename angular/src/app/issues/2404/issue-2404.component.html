Issue #2404: Angular Input TrailingIcon Fix

Problem

The Angular goab-input component was incorrectly rendering an icon button (goa-icon-button) instead of a simple icon (goa-icon) when the trailingIcon property was used without a click handler.

Technical Details

Root Cause: The Angular wrapper was using !!_onTrailingIconClick which always evaluated to true because it's a method reference.

Fix: Changed to use this.onTrailingIconClick.observed which correctly detects if there are actual subscribers to the event.

Result: Now properly renders goa-icon for decoration and goa-icon-button for interactive icons.
